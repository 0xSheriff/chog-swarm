# Legacy Routes

These routes are preserved from the original Chog Swarm grid-arena / race mode build.
They are fully functional but removed from main navigation as of the Pinball Pivot.

| Route | Description |
|-------|-------------|
| `/legacy/arena` | Original grid arena (race-v1 and v1.0 rulesets) |
| `/legacy/lab` | Trait Lab — race-v1 counterfactual mutation |
| `/legacy/gauntlet` | Daily Gauntlet (race-v1 time trial) |
| `/legacy/demo` | Recorded fallback demo |

**Do not delete this directory.** Old replays rely on the versioned engine.
